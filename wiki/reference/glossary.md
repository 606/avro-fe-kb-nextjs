# Glossary

Keep this page handy when you encounter Avro-specific terminology.

## Knowledge Base (KB)
Central repository that stores structured markdown documents rendered by the Next.js site.

## Wiki Link
Obsidian-style link using the `[[page-name]]` pattern. Automatically resolves to `/wiki/page-name` at build time.

## Sidebar Tree
Dynamic navigation component that mirrors the folder hierarchy inside `wiki/` for quick browsing.

## Static Export
The `next export` output that creates pure HTML/JS/CSS assets, which our GitHub Pages workflow deploys.

## Markdown Package
The archived copy of raw markdown files (`wiki.tar.gz`) included in the CI artifact, making it easy to download the source notes from any published build.
