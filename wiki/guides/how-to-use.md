# How to Use This Wiki

This guide will help you understand how to navigate and use this wiki effectively.

## Sidebar Navigation

The sidebar on the left shows a tree structure of all available pages. Click on any item to navigate to that page.

### Features:
- Collapsible folders
- Hierarchical organization
- Quick access to all pages

## Wiki Links

This wiki supports Obsidian-style wiki links:

- `[[page-name]]` - Link to a page
- `[[page-name|Display Text]]` - Link with custom text
- `[[folder/page-name]]` - Link to nested pages

## Markdown Support

The wiki supports standard markdown features:

- **Bold text**
- *Italic text*
- `Code blocks`
- Lists (like this one!)
- And more...
