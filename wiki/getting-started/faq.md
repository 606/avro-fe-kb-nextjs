# Getting Started FAQ

New to the Avro Wiki? These answers should help you get oriented quickly.

## Where do I put content?

Place markdown files inside the `wiki/` folder. Use subfolders (e.g., `getting-started/`, `guides/`, `reference/`) to keep related notes together.

## How do I create navigation links?

Use Obsidian-style wiki links such as `[[guides/how-to-use]]` or add custom text via `[[reference/api|API Reference]]`.

## Can I include metadata?

Yes. Each file can start with frontmatter:

```markdown
---
title: Page Title
description: Optional summary
---
```

## What about images?

Drop images into `public/wiki` (or any subfolder) and reference them with standard markdown syntax: `![Alt text](/wiki/your-image.png)`.
